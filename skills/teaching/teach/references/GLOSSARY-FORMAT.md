# GLOSSARY.md Format

`GLOSSARY.md` is the canonical language for this teaching workspace.

## Structure

```md
# {Topic} Glossary

{One or two sentence description of the topic.}

## Terms

**Term**:
Definition in one or two sentences.
_Avoid_: alternative terms
```

## Rules

- **Add a term only when the user understands it.**
- **Be opinionated.** Pick the best word, list others as aliases to avoid.
- **Keep definitions tight.** One or two sentences. Define what the term IS.
- **Use glossary terms inside definitions.**
- **Flag ambiguities explicitly.**
- **Revise as understanding deepens.**
