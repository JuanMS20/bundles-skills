# SaaS Video Templates

## 1. Explainer Video (60-90s)

Structure:
```
0-3s   → Logo reveal + tagline
3-15s  → Problem statement (pain point)
15-35s → Solution walkthrough (screen recording + callouts)
35-50s → Key features (3-5 with icons + text)
50-60s → Social proof / metrics
60-75s → CTA (URL, button, "Get started")
75-90s → Outro / brand logo
```

## 2. Feature Announcement (15-30s)

Structure:
```
0-2s   → "New" badge animation
2-8s   → Feature name + one-liner
8-20s  → Screen recording of feature in action
20-25s → Benefit statement
25-30s → CTA ("Try it now")
```

## 3. Changelog / Update (10-20s)

Structure:
```
0-2s   → Version number animation
2-10s  → 3 bullet points max (icon + text slide-in)
10-15s → "Update now" CTA
15-20s → Brand outro
```

## 4. Social Proof / Testimonial (15-30s)

Structure:
```
0-3s   → Quote marks animation
3-12s  → Testimonial text (typewriter or fade)
12-18s → User photo + name + role
18-25s → Metric / result ("3x faster")
25-30s → Logo + URL
```

## Design Tokens (SaaS Promo)

| Element | Spec |
|---|---|
| Resolution | 1920x1080 (landscape) or 1080x1920 (portrait for shorts) |
| FPS | 30 (web) / 60 (smooth motion) |
| Font | Sans-serif system font or Inter (readable at small sizes) |
| Colors | Brand primary + white + dark bg. Max 3 colors |
| Padding | 60px minimum from edges |
| Text size | Min 48px for headlines, 32px for body |
| Motion | Subtle > flashy. SaaS = trust, not entertainment |
